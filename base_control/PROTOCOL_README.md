# ROS 与 STM 底盘串口通信协议说明

本文档描述 **上位机（ROS base_control 节点）** 与 **下位机（STM 底盘控制板）** 之间的串口通信协议。代码实现见 `script/base_control.py`。

---

## 一、物理与链路层

| 项目     | 约定值 |
|----------|--------|
| 波特率   | **115200** |
| 数据位   | 8 |
| 停止位   | 1 |
| 校验位   | 无 |
| 接口     | 串口（如 /dev/ttyUSB0） |

---

## 二、帧格式（所有数据包统一结构）

每一帧由以下字段顺序组成：

| 字段     | 长度   | 说明 |
|----------|--------|------|
| **帧头** | 1 Byte | 固定 **0x5A** |
| **帧长度** | 1 Byte | 整帧字节数，含帧头到 CRC（即本帧总长） |
| **ID**   | 1 Byte | 下位机编号，级联预留，当前一般为 0x01 |
| **功能码** | 1 Byte | 见下文；**奇数=上位机→下位机，偶数=下位机→上位机** |
| **数据** | 0~250 Byte | 由功能码决定长度与含义 |
| **预留** | 1 Byte | 固定 0x00，协议扩展用 |
| **CRC-8** | 1 Byte | CRC-8/MAXIM，校验范围：帧头到预留（不含 CRC 自身） |

**约定**：

- 线速度单位：**m/s**，下传/上报时 ×1000 为 int16_t（有符号）。
- 角速度单位：**rad/s**，×1000 为 int16_t。
- 角度单位：**度**（如航向角 Yaw），×100 为 int16_t；部分阿克曼转向角为弧度制×1000。
- 多字节数值：**大端序**（高字节在前，MSB 在前）。

---

## 三、CRC-8 校验（CRC-8/MAXIM）

- 校验范围：从帧头到预留位（不含 CRC 字节）。
- 算法：CRC-8/MAXIM（多项式等见代码 `crc_1byte` / `crc_byte`）。
- 若 CRC 字节填 **0xFF**，下位机可视为不校验（协议说明）。

---

## 四、连接与断开

- **建立连接**：下位机收到一帧**合法协议数据**即认为连接建立；建立时 IMU 会初始化约 **2s**，此间建议以不低于 2Hz 发送指令。
- **断开连接**：连接建立后，若超过 **1000ms** 未收到新的协议内数据，下位机判定断开并**停止电机**。

---

## 五、功能码一览（与本代码相关）

| 功能码 | 方向 | 说明 | 数据长度 |
|--------|------|------|----------|
| **0x01** | 上→下 | 速度控制（vx, vy, vz ×1000） | 6 Byte |
| **0x02** | 下→上 | 速度设置失败应答（少见） | 1 Byte |
| **0x03** | 上→下 | 速度查询（旧） | 0 Byte |
| **0x04** | 下→上 | 当前速度（vx, vy, vz ×1000） | 6 Byte |
| **0x05** | 上→下 | 查询 IMU（欧拉角，旧） | 0 Byte |
| **0x06** | 下→上 | IMU 欧拉角（Pitch/Roll/Yaw ×1000） | 6 Byte |
| **0x07** | 上→下 | 查询电池 | 0 Byte |
| **0x08** | 下→上 | 电池电压×1000、电流×1000 | 4 Byte |
| **0x09** | 上→下 | 获取里程计（旧，无 Vy） | 0 Byte |
| **0x0a** | 下→上 | 速度+航向（vx×1000, yaw×100, vz×1000） | 6 Byte |
| **0x11** | 上→下 | 获取里程计（新，含 Vy） | 0 Byte |
| **0x12** | 下→上 | 速度+航向（vx, vy, yaw×100, vz）各×1000/×100 | 8 Byte |
| **0x13** | 上→下 | 查询 IMU 原始数据 | 0 Byte |
| **0x14** | 下→上 | IMU 原始：陀螺×100000、加速度×100000、四元数×10000 | 32 Byte |
| **0x15** | 上→下 | 阿克曼速度控制（speed×1000, 转向角×1000 弧度） | 6 Byte |
| **0x19** | 上→下 | 查询超声波 | 0 Byte |
| **0x1a** | 下→上 | 超声波测距值 4 个（cm） | 4 Byte |
| **0x21** | 上→下 | 获取底盘配置信息 | 0 Byte |
| **0x22** | 下→上 | 配置：类型、电机、减速比×10、轮径×10 | 6 Byte |
| **0xf1** | 上→下 | 查询版本号 | 0 Byte |
| **0xf2** | 下→上 | 硬件版本 3 字节 + 固件版本 3 字节 | 6 Byte |
| **0xf3** | 上→下 | 查询 SN | 0 Byte |
| **0xf4** | 下→上 | SN 12 字节 | 12 Byte |

---

## 六、本代码中的收发关系

- **0x01**：`cmdCB` 发送；下位机执行，失败时 **0x02** 应答（本代码未解析 0x02）。
- **0x15**：`ackermannCmdCB` 发送；阿克曼车速度+转向角。
- **0x09 / 0x11**：`timerOdomCB` 发送；下位机用 **0x04 / 0x0a / 0x12** 应答，在 `timerCommunicationCB` 中解析并更新 Vx/Vy/Yawz/Vyaw，供里程计与 TF 使用。
- **0x07**：`timerBatteryCB` 发送；下位机 **0x08** 应答，解析后发布电池话题。
- **0x13**：`timerIMUCB` 发送；下位机 **0x14** 应答，解析后发布 IMU 话题。
- **0xf1 / 0xf3 / 0x21**：`getVersion` / `getSN` / `getInfo` 发送；下位机 **0xf2 / 0xf4 / 0x22** 应答，在 `timerCommunicationCB` 中解析。

接收统一在 **timerCommunicationCB**（1kHz 定时器）中：串口数据先入环形队列，再按 0x5A 帧头与长度组帧，CRC 校验后按功能码解析并更新成员变量。
